# 架构决策记录（ADR）

本目录记录**已经定型的架构决策**：为什么这么选、放弃了什么、代价是什么、证据在哪。

## 规则

1. **编号四位递增、永不复用。** 形如 `0007-short-slug.md`。
2. **决策不可改写，只能被取代。** 已接受的 ADR 不修改结论；后来的变化要新增一份 ADR，
   并在新 ADR 里写「取代 00xx」，同时在旧 ADR 的状态行标注「已被 00xx 取代」。
3. **每条 ADR 必须有证据出处。** 指向仓库内文档的相对链接；实测数字必须能在出处里找到。
4. **写清代价。** 只写好处不写代价的 ADR 没有价值——本项目的多数决策都是"用 A 换 B"。
5. 状态取值：`提议` / `已接受` / `已被 00xx 取代` / `已废弃`。
